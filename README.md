🔑 API Key Setup (Important)

This project requires a Google Gemini API Key to run.
For security reasons, the API key is not included in the source code.

👉 How to Add Your Own API Key

1. Get your API key from:
https://aistudio.google.com/apikey

2. Open the project file where this line appears:
API_KEY = "YOUR_API_KEY_HERE"

3. Replace "YOUR_API_KEY_HERE" with your actual Gemini API key.
